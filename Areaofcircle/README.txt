Circle Area Calculator

This program is designed to calculate the area of a circle using the user's radius input.

!HOW TO RUN!
1. Ensure Python 3.x is installed. If not, go ahead and install it.
2. Ensure Visual Studio Code is installed. Install if not, and open it.
3. Refer to the recommended workflows for repository if unsure.
4. Open the python_fundamentals folder.
5. Open the areaofcircle file in the Files tab.
6. Select areaofcircle.py.
7. Install Microsoft Python Extension if requested.
8. Trust file.
9. Click the run button on the top banner of the terminal.
10. In the terminal box below, enter your value and press Enter.
11. If you do not see the terminal box in the bottom section, press "ctrl + `".

!! In the terminal box below, there should be a statement "Please enter your circle radius:" printed with a box next to it for a number to be entered.

Testing done via entering negative number and "3" spelled out as "three".

Assumptions:
~ Decimals are allowed.
~ Radius is unable to be negative.
~ User is familiar enough with tools to not require providing install instructions.
