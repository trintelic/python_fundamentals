U.S. Presidents List for python_fundamentals

This program runs a list of presidents (10) in chronological order following George Washington's presidency
  and marks an asterisk ("*") beside last names that begin with the letter "A".

Two Lists Are Ran Using the For Loop and the While Loop.

!HOW TO RUN!
1. Open Trintelic GitHub repository.
2. Download presidents_list repository.
3. Make sure Python 3.x and Anaconda are installed on computer and installed as an add-on
  in Visual Studio Code.
4. Open Visual Studio Code.
5. Open presidents_list.py in Visual Studio Code.
6. Click play button in upper bar of terminal.
7. Look beneath each code section and identify names that contain an asterisk next to them.

** There should be two lists printed, both with asterisks next to presidents with
   a last name beginning with an A. **


Concepts Applied:
~ For Loops
~ While Loops
~ Conditional Statements (if/else)
~ String Manipulation Using split() and startswith()
~ Lists
~ Output Formatting

Assumptions:
~ Program does not require user input.
~ Program used is capable of running Python 3.x code.
~ Asterisk condition checks president's last name.
